# Two-panel Form (React + TypeScript + Material UI)

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

Open the URL shown (usually http://localhost:5173) to see the form with 8 text fields split into two panels.

Notes:
- This project uses Vite for fast dev server and build.
- Material UI is used for layout and `TextField` components.
